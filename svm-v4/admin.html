🎊 End Election Manually

Immediately close voting and switch the public page to CLOSED state. Use this to end the election before the timer expires, or if no timer was set.

⚠ Reset All Data

Clears all locally stored vote hashes, timer settings, and election state. ThingSpeak data is NOT affected. Use to start a fresh election session.

ℹ How vote privacy works:
The public page (index.html) shows only total votes cast and turnout % — never per-party counts or percentages.
This prevents voters from sharing "Party X is winning" before the election closes, which could influence others.
Admins on this panel can see full per-party breakdown at all times for monitoring.
